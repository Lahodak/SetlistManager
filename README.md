# SetlistManager
App for managing and creating new setlist based on a collection of songs. 

# Features:
- Creation of setlists
- Showing complex details of songs
- Adding songs to database
- Saving randomly generated setlists
- Retrieving saved setlists

# Technologies used:
- ASP.NET Core Web Api
- .NET Blazor
- External Lyrics API
- .NET 8.0 based
