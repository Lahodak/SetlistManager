# SetlistManager
App for managing and creating setlists based on a collection of songs. 

# Features:
- Creation of setlists
- Showing complex details of songs
- Adding songs to database
- Saving randomly generated setlists
- Retrieving saved setlists

# Technologies used:
- ASP.NET Core Web API
- .NET Blazor
- External Lyrics API
- .NET 10.0
- MudBlazor powered UI
